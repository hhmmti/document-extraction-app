# F5 clarification (draft, not applied)

Clarifies `f5-baker.md` §5.

> §5: "Emit sensitivity rows to `stg_design_context` and `stg_curve_observations` with `scenario_label_staged = <case name>` and `sensitivity_case = true`."
>
> §5: "`scenario_selection_rule = 'p1_summary_base_case'`."

**Clarification.** `scenario_selection_rule` is required, not optional: it is written on the p1 summary case's `stg_design_context` row, the table whose schema carries the column, with the value §5 gives. `<case name>` is the case's label exactly as printed, whole; it is never shortened to its case number or otherwise abbreviated.

**Example (§5).** `scenario_selection_rule = 'p1_summary_base_case'`.
