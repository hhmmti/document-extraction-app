# F7 clarification (draft, not applied)

Clarifies `f7-valiant.md` §6 T3 and its 2026-08-20 correction.

> §6 T3: "`Turpin PHI` **and** `Dunbar PHI` (`F7-40`). Emit **both**, each labelled."
>
> §6 T3 correction: "**Resolution: `dunbar_indicator_as_printed` alongside `turpin_indicator_as_printed`**, both paired with `correlation_as_printed`."

**Clarification.** `correlation_as_printed` names the correlation, as the staging schema's column comment lists its values (`Turpin | Dunbar | ...`), and never the indicator label `PHI`. On the stage that prints both indicators it names both correlations, while each value stays in its own indicator column.

**Example (§6 T3).** `Turpin PHI` and `Dunbar PHI` (`F7-40`) give `correlation_as_printed` the names `Turpin` and `Dunbar`.
